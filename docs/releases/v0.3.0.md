# RPipe v0.3.0

## 一、阶段成果

本版本将旧 main 的脚本式研究执行迁移为可安装的 `rpipe` 库，交付 Study / Experiment / Run 编排、原生训练与评测、结果聚合、checkpoint 与故障保护，以及可复跑的 main 对照成果。完整改前/改后表见 [SUMMARY](../SUMMARY.md)。

| **改前** | **本版本** |
| --- | --- |
| 从 `src/` 运行训练、评测、配置和处理脚本 | 安装 `rpipe`，通过统一 CLI 与 Study YAML 执行研究 |
| 全局 cfg、control_name / tag 和旧 output 目录约定 | 四层配置、因素 × seed 的 Run ID，以及 Study / Run 的产物合同 |
| 历史曲线接入主要是临时单 seed 前缀探针 | 正式历史 Study 与冻结来源，32条四 seed 连续80000-step训练和32条自身 best 评测 |
| 首页使用旧 README 图 | `asset/` 展示本次完整实测曲线，旧图逐字节保存在历史参考归档中 |
| 仅 Linux / Python3.10 core 与 wheel 轻量 import 门 | Linux / Windows CPU 门及 wheel / sdist 分别安装后的公开 CLI 门 |

## 二、结果与适用范围

- 历史八组曲线通过预先固定的图像估读合同，最大终点误差0.207502个百分点。原历史逐点指标、实际 seed 和环境未知，图像估读不等于恢复原始日志。
- 当前设备现代 main 对照为8组合、seed0、60-step；使用原 Stats 全精度 profile 与统一确定性条件，16段参数最大差0。原默认条件的未通过结果保留。
- 本机 CPU 验收为288 passed / 3 deselected，限定 c1/c2、非 external / GPU / slow；wheel 与 sdist 各完成9命令、4个 Toy/Stub Run与2个 Experiment。
- 本机包验收复用了现有科学依赖，不能替代全新依赖解析；公开版本对应的远端矩阵以 [Actions](https://github.com/diaoenmao/RPipe/actions) 为准。
- 原始 Run 数据、日志和 checkpoint 留在本机忽略目录；声明、入口、正式报告、来源清单和图随仓库交付。原失败、恢复记录及旧日期快照保留。
- 科学来源与报告由 `.gitattributes` 保留实测时的原始字节，包括 CRLF / LF，避免不同系统 checkout 改变 SHA。91个生产文件的逻辑内容不变；Git中换行表示调整与发布成果分开提交。

完整证据见 [历史 Study](../../studies/main_historical/README.md)、[现代本机结果](../../studies/main_reproduction/docs/CURRENT_DEVICE_RESULT.md)、[仓库整理验收](../REPOSITORY_CLEANUP.md)。

## 三、安装与迁移

```bash
python -m pip install -e ".[dev]"
python -m rpipe run studies/<name> --skip-launch
python -m rpipe launch studies/<name>
```

旧脚本、全局 import、字典 batch 和 checkpoint 文件格式需要迁移；没有已验收的通用旧 checkpoint 转换器。现有恢复保护不承诺 RNG / sampler 与无中断训练逐位一致。旧 main `98648f3` 与历史来源 `4ccb28d` 仍可由 Git 历史读取；保留旧产物用于读取与回退。

迁移字段、Stats精度、std口径和恢复边界见 [MAIN_MIGRATION](../MAIN_MIGRATION.md)，正式操作指南见 [STUDY_GUIDE](../STUDY_GUIDE.md)。历史配方须使用其专用 Registry 入口。

## 四、分支约定

发布后的长期分支仅保留 `main` 与 `dev`，两者同步本阶段成果。阶段版本为 `v0.3.0`；后续研究与开发从 `dev` 继续，经过实际测试与审查后再进入 `main`。
