# RPipe v0.1.0

## 中文

首次正式标记改造前的 main，固定提交为 [`98648f3`](https://github.com/diaoenmao/RPipe/commit/98648f3a5c7db7dccf3ca806410d5b6fdee9484c)。此标签在本次发布时补建，原提交日期为 2025-08-18；不表示当时已经发布 v0.1.0。

- 保留 `src/` 中的 make、train、test、process 脚本、全局 `cfg`、YAML 配置及旧 `output/` 目录约定。这是原源码快照，尚无可安装的 `rpipe` 包。
- [`e01613a`](https://github.com/diaoenmao/RPipe/commit/e01613abbe29bc32e5fb713626e26b07ea1d3b1a)：增加数据集处理脚本与 `eval.num_steps` 配置，并修改 Accuracy 的统计实现。
- [`0c1fa7e`](https://github.com/diaoenmao/RPipe/commit/0c1fa7e)：修改训练 logger 与保存周期配置。
- [`98648f3`](https://github.com/diaoenmao/RPipe/commit/98648f3a5c7db7dccf3ca806410d5b6fdee9484c)：有配置文件时读取 YAML；没有相应文件时通过 `make_control` 解析 `control_name`。

全部 40 个已跟踪文件来自该提交，包括原 README 和两张历史曲线图。Source code 下载对应原 Git 树；附件源码清单提供逐文件 SHA256。没有为此历史快照重新执行训练或宣称恢复原始运行数据。与新版的区别见 [v0.2.0](v0.2.0.md)。

## English

The first formal release of the original main is pinned to [`98648f3`](https://github.com/diaoenmao/RPipe/commit/98648f3a5c7db7dccf3ca806410d5b6fdee9484c). This tag is created retrospectively during the current release work. The original commit is dated 2025-08-18; that date is not a historical v0.1.0 publication date.

### Contents and commit evidence

- Retains the make, train, test and process scripts under `src/`, global `cfg`, YAML configuration and the original `output/` layout. This is a source snapshot, without the installable `rpipe` package introduced later.
- [`e01613a`](https://github.com/diaoenmao/RPipe/commit/e01613abbe29bc32e5fb713626e26b07ea1d3b1a): adds dataset processing and `eval.num_steps`, and changes Accuracy aggregation.
- [`0c1fa7e`](https://github.com/diaoenmao/RPipe/commit/0c1fa7e): changes the training logger and save-period configuration.
- [`98648f3`](https://github.com/diaoenmao/RPipe/commit/98648f3a5c7db7dccf3ca806410d5b6fdee9484c): loads the YAML when available and otherwise parses `control_name` through `make_control`.

All 40 tracked files come from this commit, including the original README and both historical plots. Source code downloads contain the original Git tree; the attached source manifest provides per-file SHA256 hashes. No new training was performed for this historical snapshot, and the tag does not recover historical raw runs. See [v0.2.0](v0.2.0.md) for the new implementation.
